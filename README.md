# 🍽️ Restaurant Management System (Laravel/ Filament)

A complete production-ready **Restaurant / Hotel management system** built in **Laravel**, with multi-role dashboards including Admin, Manager, Chef, Waiter, and Cashier. The system manages orders, tables, reservations, inventory, billing, and reporting.

---

# 🚀 Features

## 👑 Admin Panel

* Full control of the entire system
* Sales & revenue dashboard
* Manage users and roles
* CRUD for all modules
* View reports and analytics

## 🧑‍💼 Manager Panel

* Live overview dashboard
* Monitor tables, orders, and reservations
* View and update inventory status
* View dishes and menu
* Staff performance analytics
* Approve reservations

## 🧍‍♂️ Waiter Panel

* Start new orders
* Add dishes to existing orders
* View assigned tables
* Update status (served)
* View reservations
🧰 Tech Stack

Backend: Laravel

UI: Filament  Panel

Database: MySQL
